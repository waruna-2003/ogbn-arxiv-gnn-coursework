# CCS4354 OGBN-Arxiv Coursework

This repository is organised by purpose. Start here; the folders below contain the implementation,
application, experimental outputs, and local data.

## Structure

```text
.
|-- README.md                 Project guide and run commands
|-- requirements.txt         One dependency list for the whole project
|-- Technical_Report.docx    Complete technical report; fill member identity fields before submission
|-- notebook/
|   |-- CCS4354_OGBN_Arxiv_Coursework.ipynb
|   |                          Clean shared notebook; members add code on feature branches
|   |-- reference/
|   |   `-- Coursework_Executed_Reference.ipynb
|   |                          Protected copy of the verified executed notebook
|-- dashboard/
|   |-- app.py                Streamlit application for Task 08
|   |-- README.md             Dashboard-specific explanation

|   `-- screenshots/          Task 08 evidence images for report/submission
|-- data/

`-- .venv/                    Installed Python environment; do not submit or edit
```

## What belongs where

- `notebook/CCS4354_OGBN_Arxiv_Coursework.ipynb` is the clean shared development notebook. It
  contains the coursework headings and explanations but no implementation cells. Members add code
  only inside their assigned section and submit the same notebook through separate feature branches.
- `notebook/reference/` preserves the complete verified executed notebook. It is a recovery and
  comparison copy; members must not edit it or submit it as their branch work.
- `dashboard/` is the interactive application. Its `artifacts/` directory contains only outputs
  generated by the notebook and consumed by `app.py`.
- `data/` contains the large downloaded dataset. It is required for retraining but is normally not
  included in a coursework submission because OGB can download it again.
- `.venv/` contains third-party Python packages installed on this computer. It is not project
  source and is excluded from Git/submission packaging.
- `requirements.txt` is the single source of dependency information.

## Run the dashboard

From this directory:

```powershell
.\.venv\Scripts\python.exe -m streamlit run dashboard\app.py
```

The regular tabs use saved real results. Full-graph inference starts only after pressing
**Run live inference**.

## Open the notebook

```powershell
.\.venv\Scripts\python.exe -m jupyter lab notebook\CCS4354_OGBN_Arxiv_Coursework.ipynb
```

Run Jupyter from this root directory because notebook paths are deliberately relative to the
project root.

## Five-member notebook workflow

| Member | Assigned work | Branch |
|---|---|---|
| Member 1 | Tasks 01–02: tensors and graph analysis | `feature/member-1-tensors-graph` |
| Member 2 | Task 03 and GCN | `feature/member-2-data-gcn` |
| Member 3 | GAT and Task 05 training | `feature/member-3-gat-training` |
| Member 4 | Tasks 06–07 evaluation and explainability | `feature/member-4-evaluation` |
| Member 5 / Project Owner | Dashboard prototype, extended work and final integration | `feature/owner-prototype-integration` |

Every member adds code cells only below their assigned notebook headings. Before editing, pull the
latest `main`; after completing the section, commit the single canonical notebook and open a pull
request. The project owner merges branches one at a time and resolves any notebook JSON conflicts.

## Regenerated undirected dashboard artifacts

The saved artifacts were generated previously using the original directed citation graph for
descriptive statistics and a symmetrised edge index for GNN message passing. They remain installed
in `dashboard/artifacts/` and validated against the dashboard while members rebuild the notebook.

Current headline results:

- GCN test accuracy: **71.71%**; macro F1: **0.5054**.
- GAT test accuracy: **70.72%**; macro F1: **0.4781**.
- Live inference graph: **169,343 nodes** and **2,315,598 undirected message-passing edges**.

After all five branches are merged, regenerate them as follows:

1. Upload `notebook/CCS4354_OGBN_Arxiv_Coursework.ipynb` to Google Colab.
2. Select **Runtime > Change runtime type > T4 GPU**.
3. Confirm every assigned section now contains its completed code cells.
4. Choose **Runtime > Run all**. The first run downloads OGBN-Arxiv automatically.
5. Let the final artifact cell create `dashboard_artifacts_undirected.zip`.
6. Extract that ZIP into `dashboard/artifacts/`, replacing the old generated files only after the
   notebook has finished without errors.

A local GPU is not required. The 2 GB GPU detected on this computer is too small for the full
undirected GAT run; Colab's T4 is the intended regeneration environment.

## Recreate the environment

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

The technical report is now included as `Technical_Report.docx`. Before submission, replace the
bracketed member names, student IDs, and agreed contribution percentages. Slides, GitHub
information, and the video remain separate coursework deliverables. Generate the final submission
ZIP only after those items are complete.
